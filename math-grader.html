1多模态大模型 API 设置

本系统采用 OpenAI 兼容 的 Chat Completions 多模态接口（支持图片 / PDF 转图片）。 可填写任意兼容服务，如 OpenAI(gpt-4o)、通义千问 VL、智谱 GLM-4V、Kimi、DeepSeek-VL、本地 Ollama 等。 接口地址填写到 /chat/completions 的前缀，例如 https://api.openai.com/v1。
⚠️ 浏览器直连大模型可能遇到 CORS 跨域限制，若报错请使用允许浏览器跨域的 API 服务或自建反代。
点此自动生成自包含启动脚本（跨电脑/系统通用），双击运行后网页会自动连接；无需手动找 proxy.js。
💡 若把本网页部署到 GitHub Pages 等 https 环境，大模型接口自带跨域放行，可完全免代理直连（取消勾选“使用本地代理”即可）。本地 file:// 打开才需要代理。

2上传参考答案 → AI 解析评分标准

上传参考答案的 图片或多页 PDF，系统调用 Prompt1 自动解析为结构化评分标准， 解析结果以可编辑表格呈现，请老师核对、修改后 确认启用，方可进入批改。

3上传学生作业 → AI 按标准批改

需先完成“参考答案解析”并 确认启用。系统把每份作业拆分为客观题和主观题两类分别评阅： 客观题由老师录入答案后前端离线判分（不调模型、秒出）；主观题调用 Prompt2 分步批改。 可在上方批改模式中选择“完整试卷 / 仅批客观题 / 仅批主观题”，想批哪部分就批哪部分，二者可分开进行。
默认“完整试卷”：客观题离线判分 + 主观题调大模型，二者合并为总分与学情。

📝 客观题评阅（选择 / 填空）

此区域只处理题型为“客观题 / 选择题 / 填空题”的题目，由系统离线比对标准答案立即判分，零大模型调用、秒出结果。 请按“题号:答案”逐行录入；未填的题按 0 分计并标记【待复核】。 完整试卷模式下，上传的客观题作业图片会一并送给大模型作为参考。
一键填入客观题标准答案，老师再改错的题为学生实际作答

🖊️ 主观题评阅（计算 / 解方程 / 几何证明 / 应用题）

此区域处理计算题、解方程、几何证明、应用题等题型。请上传该生作业图片或 PDF，系统逐页转图后调用大模型 按解题步骤分步给分；潦草手写、跳步、定理错误等均会标注。

📑 学生作业文件（完整试卷）

上传该生完整作业图片或 PDF。客观题由系统离线比对标准答案立即判分；主观题由大模型按解题步骤分步给分。 若试卷包含手写客观题，上传图片后大模型会辅助识别与核对。
一键填入客观题标准答案，老师再改错的题为学生实际作答
