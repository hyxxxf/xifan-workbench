# 2026-08-19 工作记录

## 希凡工作台第七轮（提醒事项紧急度改按截止时间判定）
- 需求：原版首页「提醒事项」的紧急/正常按**分类写死**（班级事务/材料上交=正常、家校沟通/安全排查=紧急），与截止时间无关；用户要求改为**按 deadline 自动判定**。
- 改动：`renderHomeReminder()` 中删除 `tagClass`/`tagText` 写死映射（班级事务→normal、家校沟通→urgent、材料上交→steady、安全排查→urgent），新增 `todoUrgency(t)` 函数按 `deadline` 计算：
  - 逾期（days<0）或 ≤2 天 → `urgent`（红，文案「逾期」/「紧急」）
  - 3~7 天 → `steady`（蓝，文案「临近」）
  - >7 天 或无期限 → `normal`（绿，文案「正常」）
- deadline 字段格式为 `YYYY-MM-DD`（日期输入框值 + addDays 生成的 toISOString 切片），`todoUrgency` 用 `new Date(+y,+m-1,+d)` 本地解析避免 UTC 偏移。
- 注意：全部待办弹窗（refreshTodoModal）与待办列表（renderTodoList）里仍显示**分类** `tag`，未动；只改了首页提醒事项的紧急度着色，符合用户「提醒事项」范围。CSS 已有的 `.remind-tag.normal/.urgent/.steady` 三色直接复用。
- 校验：`node --check` 通过；grep 确认 `tagClass`/`tagText` 已无残留引用。
- 待确认：阈值为合理默认，用户可能想调整（如「≤2天=紧急」改为「≤3天」等）。
